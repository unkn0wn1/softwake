# Glossary

Short names for paths. A whole token expands before a confirm readback. Put real paths in the config copy of this file (`$XDG_CONFIG_HOME/softwake/soul/glossary.md`, or `~/.config/softwake/soul/glossary.md` when `XDG_CONFIG_HOME` is unset).

docs → /path/to/docs
notes → /path/to/notes
