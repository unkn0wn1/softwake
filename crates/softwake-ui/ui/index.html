    General

    Agent name and soul-pack editors live under Profiles. Each profile has its own name plus soul.md, user.md, rules.md, and glossary.md. Switch the active profile there; Reload soul applies a valid pack on the next awake.

    Scales labels across every Settings pane. Buttons stay compact. Saved under the Softwake config root.

    After the pointer leaves the expanded HUD, it collapses back to the square bloom. A non-empty ask draft keeps it open. Range 1–30 seconds, default 3. Saved in ui-prefs.json as hud_idle_collapse_ms (1000–30000). The HUD re-reads that file; softwaked does not restart.

    Lower = easier match (0.05–0.50). Defaults 0.15 global / 0.10 short. Saved to softwake.json and applied live to the running daemon. Short-word covers sleep / hi / product softwake. The active profile name and hey <name> get an extra ease automatically (names like sally under-fire vs product tokens at the same short setting). Dragging the sliders debounces live reload (~450 ms). Env SOFTWAKE_KWS_THRESHOLD / SOFTWAKE_KWS_SHORT_THRESHOLD still win on rebuild if set.

    How long quiet after speech before Softwake ends the utterance and runs STT. Press-to-talk ignores this. This is not wake-word sensitivity. Range 0.5–4.0 s, default 2.0. Saved to softwake.json (free_speech_end_silence_ms, 500–4000) and applied live. Changes debounce about 450 ms. Env SOFTWAKE_FREE_SPEECH_END_SILENCE_MS wins over the file when set.

    How long Eve may keep speaking before the playback reaper stops the player. The written reply is not cut. Range 30–300 seconds, default 60. Saved in softwake.json as tts_playback_timeout_ms (30000–300000). The next speak uses the new value. An in-flight clip keeps the deadline it started with. Changes debounce about 450 ms. Env SOFTWAKE_TTS_PLAYBACK_TIMEOUT_MS wins over the file when set. Chat wait stays 120 seconds. Free-speech silence, wake-word sensitivity, HUD idle collapse, and the short mute after playback are unchanged.

    Wake, sleep, and deep-sleep phrases still change state, and Softwake still speaks the short state line. Microphone speech is not sent to the chat model. Default off. A serve restart clears this unless serve was started with --voice-test.

    Tools

    Each registered tool is Always allow, Ask, or Deny. Defaults: echo always allow, notify and email send ask, shell deny. Shell confirm policy applies when shell is Ask. Glossary aliases still expand before a shell command runs. This page does not enable email sign-in.
