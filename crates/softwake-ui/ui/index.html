    General

    Agent name and soul-pack editors live under Profiles. Each profile has its own name plus soul.md, user.md, rules.md, and glossary.md. Switch the active profile there; Reload soul applies a valid pack on the next awake.

    Profiles

    Each profile has an agent name and its own soul pack. The active profile is what the daemon loads when Softwake wakes (unless SOFTWAKE_SOUL_DIR / --soul-dir overrides). Edit the selected profile below; Set active updates softwake.json and reloads soul when the pack is valid. Create a blank profile from the left sub-menu.
