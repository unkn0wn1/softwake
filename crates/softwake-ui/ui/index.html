    Tools

    Softwake is not full machine access. Tools stay off until you enable them here. Shell (including ssh via a glossary alias) always confirm-echoes by default. Add host aliases in the active profile glossary.md, then Reload soul.

    Glossary format: aau → ssh -l root aau (or ASCII ->). Spoken: “ssh to aau and check swap” expands, then waits for Confirm on Status.

    Email

    Live email is off by default. Softwake still uses the in-memory mock outbox until you enable live email. Sending stays confirm-gated on the Status pane; this pane never sends mail. Draft-only mode stores a local draft after confirm. Real SMTP is not wired in this scaffold.
